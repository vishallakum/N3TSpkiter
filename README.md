# N3TSpkiter

N3TSpkiter is a Python-based network scanning and reconnaissance CLI tool designed for security labs, learning, and authorized network testing.

## Features

* Host availability checking
* TCP port scanning
* Service detection
* Network reconnaissance
* OS fingerprinting using local signatures
* Configurable scan ports and intensity
* Scan result reporting
* Interactive CLI interface
* JSON-based signature databases


## Requirements

* Python 3

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/N3TSpkiter.git
cd N3TSpkiter
```

Run the tool:

```bash
python3 n3tspkiter.py
```
